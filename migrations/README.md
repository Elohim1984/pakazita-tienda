# Migrations scaffolding

This directory holds database migration scripts managed by Flask-Migrate / Alembic.

What I added
- A placeholder `.gitkeep` so the folder is tracked.
- This README explaining how to initialize and generate migrations locally.

Why I didn't autogenerate migrations
- I can't run Flask-Migrate in your environment from here because I don't have an execution environment with your app's runtime and database connection. To create accurate migrations Alembic must inspect your SQLAlchemy models locally or in an environment with access to your code and DATABASE_URL.

How to initialize and create migrations locally (recommended)

1) Ensure dependencies are installed:

   python -m venv .venv
   source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt

2) Ensure FLASK_APP and DATABASE_URL are set:

   export FLASK_APP=app.py
   export DATABASE_URL='postgres://user:pass@host:port/dbname'

3) Initialize Alembic (only once):

   flask db init

4) Create a migration from your models:

   ./scripts/run_migrations.sh migrate "initial schema"

5) Apply the migration to the DB:

   ./scripts/run_migrations.sh upgrade

6) Commit the `migrations/` folder to source control:

   git add migrations
   git commit -m "Add DB migrations"
   git push origin main
